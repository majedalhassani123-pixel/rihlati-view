رحلاتي – مشاهدة فقط | حزمة PWA تجريبية

1. أنشئ مستودع GitHub عامًا جديدًا باسم rihlati-view.
2. ارفع محتويات هذا المجلد إلى جذر المستودع: index.html وmanifest.webmanifest وservice-worker.js ومجلد icons.
3. افتح Settings > Pages، واختر Deploy from a branch ثم main و/(root) ثم Save.
4. بعد نشر GitHub Pages، افتح رابط https://USERNAME.github.io/rihlati-view/ على هاتفك.
5. آيفون: Safari > مشاركة > إضافة إلى الشاشة الرئيسية.
6. أندرويد: Chrome > القائمة > تثبيت التطبيق أو إضافة إلى الشاشة الرئيسية.

مهم:
- هذا غلاف PWA تجريبي، وليس تطبيقًا أصليًا أو ملف APK/IPA.
- قد يمنع Google Apps Script عرضه داخل iframe؛ عندها سيعمل زر فتح رحلاتي فقط، وقد يظهر شريط المتصفح.
- هذا الغلاف لا ينشئ حماية صلاحيات. يجب حماية عمليات التعديل والحذف في Google Apps Script.
- GitHub Pages استضافة عامة؛ لا ترفع إليها بيانات أو رموز وصول سرية.
- لواجهة كاملة مستقلة مضمونة، انقل واجهة HTML إلى الاستضافة نفسها مع واجهة API آمنة أو استخدم تطبيقًا أصليًا.
